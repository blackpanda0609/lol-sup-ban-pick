# Natural Japanese

日本語ネイティブが読んで引っかからない文章を書くためのルール。

## 基本方針

- 文体は「です・ます調」で統一する。ユーザーが別の文体を指定した場合はそちらに従う。
- 一文は短く。目安は60字以内。長くなったら句点で切る。
- 結論を先に書き、理由や補足はあとに回す。
- 読み手がすでに知っていることは繰り返さない。

## 翻訳調を避ける

| 避ける | 自然な書き方 |
| --- | --- |
| 〜することができます | 〜できます |
| 〜を行います / 〜を実施します | 〜します |
| 〜することが可能です | 〜できます |
| 〜であるところの | （削る。関係節を前に置く） |
| 彼は / 彼女は / それは | 主語が明らかなら省く。代名詞より名詞を繰り返す |
| 〜によって〜される（受け身の多用） | 能動態にする |
| 〜に関しては / 〜について言えば | 〜は |
| 非常に / 大変（の多用） | 必要なときだけ使う |
| 〜を確認してください。（命令の連続） | 手順なら番号付きリストにする |

- 英語の語順をなぞらない。修飾語は被修飾語の直前に置く。
- 「私は」「あなたは」はほぼ省略する。
- 英単語をむやみにカタカナ化しない（「リクエストをハンドリングする」→「リクエストを処理する」）。ただし、技術用語として定着している語（コミット、ブランチ、デプロイなど）はそのまま使う。

## 表記

- 全角と半角の間にスペースは入れない（例:「GitHubのリポジトリ」）。プロジェクトに既存の表記ルールがあればそちらに合わせる。
- 句読点は「、」「。」を使う。
- 数字・英字は半角。
- 「下さい」「出来る」「事」「時」は、補助的な用法ではひらがなにする（ください／できる／こと／とき）。
- 感嘆符や絵文字は、ユーザーが使っていない限り使わない。

## 敬語

- 過剰な敬語を避ける。「〜させていただきます」は「〜します」で足りる。
- 「〜と思います」を連発しない。事実なら言い切る。不確かなら何が不確かかを書く。

## 見直しチェックリスト

書き終えたら次を確認する。

1. 声に出して読んだとき、つっかえる箇所がないか。
2. 「こと」「の」「を行う」が一文に何度も出ていないか。
3. 主語や代名詞を省いても意味が通る箇所に、余分な主語が残っていないか。
4. 同じ語尾（〜です。〜です。〜です。）が3回以上続いていないか。
5. カタカナ語を和語・漢語に置き換えたほうが伝わる箇所がないか。
